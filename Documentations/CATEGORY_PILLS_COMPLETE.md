## 📞 Quick Troubleshooting

### Animation not smooth?
→ Check browser hardware acceleration is enabled
→ Verify GPU not busy with other tasks

### Colors not showing?
→ Verify Chakra UI color names exist
→ Check browser console for errors

### Mobile text not hidden?
→ Verify responsive props: `display={{ base: 'none', md: 'inline' }}`
→ Clear browser cache

### Icons not displaying?
→ Verify all icon imports are correct
→ Check icon names in category definition
