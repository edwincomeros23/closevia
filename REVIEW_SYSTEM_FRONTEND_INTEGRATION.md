# Review System Frontend Integration Guide

## Overview
The frontend needs to be updated to support:
1. **Immutable Initial Reviews**: Display locked initial review with "locked" badge
2. **Follow-up Reviews**: Allow users to submit follow-up reviews with rating adjustments
3. **Dynamic Display**: Show initial (locked) + latest (active) review
4. **Media Display**: Lightbox for proof photos
5. **Rating Trends**: Show ↑↓→ indicators for rating changes
6. **Auto-completion**: Handle auto-generated default reviews from scheduler

```typescript
const submitReview = async () => {
  if (rating < 1 || rating > 5) {
    toast({
      title: 'Error',
      description: 'Please select a rating',
      status: 'error',
      position: 'top'
    });
    return;
  }

  if (!feedback.trim()) {
    toast({
      title: 'Error',
      description: 'Please provide feedback',
      status: 'error',
      position: 'top'
    });
    return;
  }

  // For initial reviews (non-followup), photo is mandatory for meetup/delivery
  const needsPhoto = !showFollowupForm && (trade?.tradeOption === 'meetup' || trade?.tradeOption === 'delivery');
  if (needsPhoto && !proofFile) {
    toast({
      title: 'Error',
      description: 'Photo evidence is required for ' + (trade?.tradeOption || 'this trade'),
      status: 'error',
      position: 'top'
    });
    return;
  }

  setSubmitting(true);
  try {
    let proofURL = proofImage || null;

    // Upload photo if provided
    if (proofFile) {
      const formData = new FormData();
      formData.append('image', proofFile);
      formData.append('type', 'trade_review');
      
      const uploadRes = await fetch('/api/upload', {
        method: 'POST',
        headers: { 'Authorization': `Bearer ${authToken}` },
        body: formData
      });

      if (!uploadRes.ok) throw new Error('Failed to upload proof photo');
      
      const uploadData = await uploadRes.json();
      proofURL = uploadData.url;
    }

    // Submit review
    const reviewPayload: TradeReviewPayload = {
      rating,
      feedback,
      proofUrl: proofURL || undefined,
      isCameraPhoto: !!proofFile,
      isFollowup: showFollowupForm
    };

    const response = await fetch(`/api/trades/${tradeID}/reviews`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${authToken}`
      },
      body: JSON.stringify(reviewPayload)
    });

    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.error || 'Failed to submit review');
    }

    const result = await response.json();
    
    toast({
      title: 'Success',
      description: showFollowupForm 
        ? 'Follow-up review submitted successfully' 
        : 'Review submitted successfully',
      status: 'success',
      position: 'top'
    });

    // Reset form
    setRating(0);
    setFeedback('');
    setProofFile(null);
    setProofImage(null);
    setShowFollowupForm(false);

    // Handle auto-completion
    if (result.data?.auto_completed) {
      toast({
        title: 'Trade Complete!',
        description: 'Trade has been automatically completed',
        status: 'info',
        position: 'top'
      });
      
      setTimeout(() => {
        onClose();
      }, 1500);
    } else {
      // Refresh review history
      await fetchReviewHistory();
    }

  } catch (err) {
    toast({
      title: 'Error',
      description: err instanceof Error ? err.message : 'Failed to submit review',
      status: 'error',
      position: 'top'
    });
  } finally {
    setSubmitting(false);
  }
};
```

### 2. Fetch Review History

Add new function to fetch reviews:

```typescript
const fetchReviewHistory = async () => {
  try {
    // Get review history
    const historyRes = await fetch(`/api/trades/${tradeID}/reviews`, {
      headers: { 'Authorization': `Bearer ${authToken}` }
    });
    
    if (historyRes.ok) {
      const historyData = await historyRes.json();
      setReviewHistory(historyData.data || []);
    }

    // Get review summary
    const summaryRes = await fetch(`/api/trades/${tradeID}/review-summary`, {
      headers: { 'Authorization': `Bearer ${authToken}` }
    });

    if (summaryRes.ok) {
      const summaryData = await summaryRes.json();
      const userSummary = userID === trade.buyerID 
        ? summaryData.data.buyer_review 
        : summaryData.data.seller_review;
      setReviewSummary(userSummary);
    }
  } catch (err) {
    console.error('Error fetching review history:', err);
  }
};
```

## UI/UX Considerations

### Layout Flow:
1. **Display existing reviews** (initial + latest if followup exists)
2. **Show rating trend** if followup exists
3. **Show add followup button** (if not already in followup form)
4. **Show followup form** (if user clicked "Add Follow-up")
5. **Show initial form** (if no initial review exists)

### Visual Indicators:
- **🔒 LOCKED** badge on initial review
- **📌 FOLLOW-UP #1** badge on follow-up reviews
- **↗ Rating increased by** indicator for positive deltas
- **↘ Rating decreased by** indicator for negative deltas
- **→ Auto-completed** indicator for auto-generated reviews

### Form Validation:
- Rating: required (1-5)
- Feedback: required (non-empty)
- Photo: required ONLY for:
  - Initial reviews
  - Meetup trades
  - Delivery trades
- Photo must be taken with app camera (`isCameraPhoto=true`)
